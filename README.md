# POE2 URL Opener 🎮

Path of Exile 2 다음 게임 사이트를 Microsoft Edge 브라우저로 여는 간단한 프로그램입니다.

## 🌐 대상 URL

```
https://pathofexile2.game.daum.net/main
```

## 📦 사용 방법

이 프로젝트는 3가지 버전으로 제공됩니다. 편한 방법을 선택하세요!

### 1️⃣ HTML 버전 (가장 간단!)

**파일:** `open_poe2.html`

**사용법:**
- 파일을 더블클릭하면 브라우저에서 열립니다
- "Edge로 열기" 버튼을 클릭하세요
- 또는 키보드로 `Enter` 또는 `Space` 키를 누르세요

**특징:**
- 설치 불필요
- 예쁜 UI
- Windows에서 Edge 프로토콜을 사용하여 Edge로 직접 실행

---

### 2️⃣ Windows 배치 파일 (빠른 실행)

**파일:** `open_poe2.bat`

**사용법:**
- 파일을 더블클릭하면 즉시 Edge로 사이트가 열립니다
- Windows 전용

**특징:**
- 클릭 한 번으로 바로 실행
- 별도 설치 불필요
- Edge 자동 감지

---

### 3️⃣ Python 스크립트 (크로스 플랫폼)

**파일:** `open_poe2.py`

**사용법:**

```bash
# 명령줄에서 실행
python open_poe2.py

# 또는 더블클릭으로 실행 (Python 설치 필요)
```

**요구사항:**
- Python 3.x 설치

**특징:**
- Windows, macOS, Linux 모두 지원
- Edge 브라우저 자동 감지
- Edge가 없으면 기본 브라우저로 대체

- **Windows 사용자**: `open_poe2.bat` (가장 빠름) 또는 `open_poe2.html` (가장 예쁨)
- **macOS/Linux 사용자**: `open_poe2.py` 또는 `open_poe2.html`

## 🔧 바로가기 만들기 (Windows)

1. `open_poe2.bat` 또는 `open_poe2.html` 파일을 우클릭
2. "바로가기 만들기" 선택
3. 바로가기를 바탕화면이나 원하는 위치로 이동
4. (선택) 바로가기 아이콘 변경 가능

- 💻 크로스 플랫폼 지원 (Python 버전)
